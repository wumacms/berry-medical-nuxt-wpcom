# 全站区块化架构（Block-Based Architecture）重构优化报告

**实施日期**：2026-09-25\
**架构理念**：网站的最小组成单元是**区块（Block）**。一个完整的网站由导航栏区块（Navbar）、页脚区块（Footer）和多个页面（Page）组成；每个页面均由清晰定义的独立业务区块组装而成。组件设计与数据结构契约均严格遵循此架构理念。

---

## 一、重构背景与目标

在重构前，部分页面（如
`advantages.vue`、`services.vue`、`contact.vue`、`industry.vue`、`cases` 和
`news` 系列）存在以下问题：

1. **页面模板冗长庞大**：一个页面文件内嵌了上百行复杂的局部卡片、轮播交互和样式模板，缺乏可读性与复用度；
2. **数据结构缺乏区块契约**：数据文件中的字段分散平铺，无法直接对应页面渲染时的独立逻辑区块；
3. **架构风格不一致**：首页（`index.vue`）已采用区块化组装（HeroSlider、ServiceFeatures、AboutPreview等），但其他内页仍为单体长模板。

**本次优化目标**：

- 确立全站统一的 **Block-Based Architecture** 契约规范；
- 将所有页面的内联模板全部抽取为独立的业务区块组件，归类至相应业务命名空间；
- 数据层全面升级为区块化数据结构（`*Block` /
  `*BlockData`），同时保持原有字段别名以保证 100% 向后兼容；
- 页面模板转变为纯声明式组装器，代码行数下降 60%~75%；
- 保持 100% 视觉表现、交互动效、响应式自适应与 SEO 元数据完整无损。

## 二、架构设计与契约定义

### 1. 类型系统契约 (`app/types/blocks.ts`)

定义了全局通用区块与各页面独立区块的 TypeScript 接口规范：

- **通用基础区块契约**：
  - `BannerBlockData`: 页面顶部横幅与面包屑区块
  - `SectionHeaderBlockData`: 通用区块标题与副标题
  - `CtaBlockData`: 行动召唤卡片与跳转按钮
  - `ArticleBlockData`: 结构化富文本文章实体（摘要、正文 HTML、标签、阅读量）
- **页面级区块契约集合**：
  - `HomePageBlocks`: 首页六大区块契约
  - `AdvantagesPageBlocks`: 专业优势页四大区块契约
  - `ServicesPageBlocks`: 服务体系页五大区块契约
  - `IndustryPageBlocks`: 行业背景页两大核心分析区块契约
  - `ContactPageBlocks`: 联系我们页三大交互区块契约
  - `AboutPageBlocks`: 关于我们页富文本与行动召唤契约
  - `CasesPageBlocks`: 产品案例列表与筛选区块契约
  - `NewsPageBlocks`: 新闻动态多风格排版区块契约

### 12. 页面横幅、文章头与面包屑解耦重构（`PageBanner.vue` & `ArticleHeaderBlock.vue` & `BreadcrumbBlock.vue`）

- **类型契约彻底净化**：在 `app/types/blocks.ts` 中彻底移除冗余过时的 `PageBannerBlockData` 和 `BannerMeta`：
  - `BannerBlockData`：普通栏目/频道页横幅纯粹契约（`title`, `description?`, `bgImage?`）；
  - `ArticleHeaderBlockData`：文章/案例详情页文章头契约（`title`, `date?`, `author?`, `views?`, `bgImage?`）；
  - `BreadcrumbItem`：独立面包屑导航项契约（`label`, `to?`）。
- **组件职责彻底解耦与去过度设计**：
  - [PageBanner.vue](file:///Users/devlink/code/github/wumacms/berry-medical-nuxt-wpcom/app/components/common/PageBanner.vue)：纯粹用于普通栏目页，移除 `size`、`headingTag`、`showBreadcrumbs`、`breadcrumbSpacing` 及 `block?: ...` 等复合属性，代码精简至 56 行，直接接收扁平清晰的 `title`、`description`、`bgImage`；
  - [ArticleHeaderBlock.vue](file:///Users/devlink/code/github/wumacms/berry-medical-nuxt-wpcom/app/components/common/ArticleHeaderBlock.vue)：专为单篇内容详情页（新闻详情、案例详情）打造，使用语义化 `<header>` 与 `<time>` 标签。彻底移除了复合实体 `article` 属性以及与面包屑职责重叠的 `category` / `categoryTo` 属性，直接接收纯扁平的 `title`、`date`、`author`、`views`、`bgImage`；
  - [BreadcrumbBlock.vue](file:///Users/devlink/code/github/wumacms/berry-medical-nuxt-wpcom/app/components/common/BreadcrumbBlock.vue)：完全独立的面包屑导航组件，支持 Schema.org `BreadcrumbList` 与 `ListItem` 标准微数据；
- **全站页面结构高度统一**：所有内页均规范为清晰的区块流：
  1. 页面视觉头（`<PageBanner>` 或 `<ArticleHeaderBlock>`）
  2. 辅助导航（`<BreadcrumbBlock>`）
  3. 业务内容区块集
